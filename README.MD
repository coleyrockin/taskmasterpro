## About

A lightweight task management application with an intuitive interface for creating, organizing, and tracking daily tasks. Built entirely with vanilla web technologies — no frameworks, no dependencies.

## Features

- Create, edit, and delete tasks
- Clean, responsive UI
- Organized task views
- Zero dependencies — pure HTML, CSS, and JavaScript
- Deployed on GitHub Pages

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 |
| Logic | JavaScript (ES6+) |
| Hosting | GitHub Pages |

## Getting Started

```bash
git clone https://github.com/coleyrockin/taskmasterpro.git
cd taskmasterpro
```

Open `index.html` in your browser.
